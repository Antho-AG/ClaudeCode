# Mon Dashboard

Dashboard personnel PWA "tout-en-un" : To Do, briefing sportif du matin, Mind Maps, journal de bord.

## Stack

- React + Vite
- Tailwind CSS
- Zustand (state + persistance)
- React Router
- React Flow (mind maps, à partir de la Phase 3)
- localStorage + IndexedDB (aucune donnée envoyée à un serveur)

## Démarrer

```bash
npm install
npm run dev
```
